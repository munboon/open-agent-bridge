# Community conduct

Treat contributors and users with respect. Discuss the work without personal attacks. Harassment, threats, discriminatory abuse, publishing private information and repeated unwanted contact are not acceptable in project issues, pull requests or other project spaces.

Mun Boon moderates this project and may remove content, close discussions or restrict participation when needed. Explain disagreements with evidence and allow others time to respond.

Use GitHub's private abuse-reporting controls for harassment or private-information exposure. Do not publish sensitive evidence in an issue. For software vulnerabilities, follow [SECURITY.md](SECURITY.md). Maintainers will consider context and repeated behavior when responding.
