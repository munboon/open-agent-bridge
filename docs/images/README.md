# Documentation images

`workspace.png` shows the workspace in light mode. `project.png` shows a project overview in dark mode. Both use fictional documentation fixtures, including the administrator, project and agents. Their status labels illustrate the interface and are not evidence of running agents or completed work.

`agent-connections.png` shows configured communication permissions for six fictional agents. Green solid links are enabled and red dashed links are disabled. This illustrates permissions, not running-agent activity.

These are browser screenshots of the application. Capture replacements with fictional data, wait for fonts and disable animations. Review visible content and metadata before committing. Keep accounts, messages, credentials and installation details out of public images.

The decorative bridge artwork's provenance is recorded under `public/art/titanium`.

## Architecture diagram

`architecture.html` is the self-contained SVG source for `architecture.png`. It embeds Manrope and its OFL notice, with no remote scripts or fonts. The palette is documented in `diagram-style.md`.

The diagram shows illustrative locations connected over HTTPS. Arrows distinguish bridge requests from an agent's local tools. Location labels contain no real hostnames or infrastructure details. The PNG export is 1440 × 880.
